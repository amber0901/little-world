# iPad性能与全屏优化

2026-11-15，版本2.4.0。目标设备为用户的iPad Pro 12.9英寸第三代、iPadOS 14.2。没有连接或远程控制该实体iPad。

## 发现与修改

1. 原地图每个D3拖动/缩放事件都调用React状态更新，使国家SVG、图片分组、foreignObject按钮与图片组件反复参与渲染。现在事件经requestAnimationFrame合并，只更新底图和可见标记的位置；手势或定位动画结束时才向React提交视图并重算分组。标记保持固定显示尺寸，分组在拖动期间保持稳定，松手后更新。地图组件及回调也保持稳定，搜索输入和播放状态改变不会无故重渲染地图。
2. 原地理归属查询在地图数据或地区筛选改变时执行，会遍历国家多边形，本机独立测得277个代表点的一次遍历约103ms；实体旧iPad耗时未测。现在将同一算法的结果预先生成到14KB的地理索引，浏览器不再执行这批多边形查询。测试确保预生成结果与原始计算完全一致。旋转和全屏引起尺寸变化时保留当前地理中心与缩放。
3. 移除底图SVG阴影滤镜及每个图片标记的drop-shadow，保留轻量边框与阴影；不为每个标记建立独立GPU图层。
4. Safari 14.2不支持原生图片懒加载。列表改用共享IntersectionObserver，只有进入或接近可视范围才插入图片；地图上已显示的分组图立即加载。详情默认选择长边不超过640的版本，点击大图才使用完整尺寸。277项主配图的最大WebP合计37,871,250字节，对应详情小图合计16,095,220字节，减少约58%；这不是一次页面访问的实际下载量。图库切换条目时同步重置，避免先请求上一个相册序号的图片。
5. CSS的dvh改为实际窗口高度变量，提供vh回退；同时增加旧Safari缺少flex gap时的间距回退。构建明确面向Safari 14，而非Vite默认的更新浏览器目标。
6. 右上角加入全屏按钮。支持标准接口、旧iPad Safari的webkitRequestFullscreen/webkitExitFullscreen及事件，状态以浏览器实际事件为准。拒绝或不支持时显示说明；同时提供添加到主屏幕的入口指引和Apple Web App元标签，不把普通CSS铺满页面伪装成原生全屏。

官方支持资料：[Safari 15.4的视口单位与原生图片懒加载](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/)、[Safari 16.4非前缀全屏接口](https://webkit.org/blog/13966/webkit-features-in-safari-16-4/)。原生全屏仍受浏览器版本、设置和用户手势约束。

## 线上只读检查

对用户提供的服务测得：HTML约0.74秒，图片索引约0.75秒/46,888字节，底图约1.25秒/75,184字节。JSON已启用Gzip和no-cache重新验证。它们是本机到服务的单次测量，不代表iPad的网络时延。拖动不需要网络请求，因此不能用增加服务器带宽来替代前端渲染优化。未修改线上服务器。

- 本地生产包使用1366×1024、1024×1366两种12.9英寸iPad尺寸检查缩放、拖动、定位、全屏进入/退出、窗口尺寸变化后的缩放保留、搜索、图库大图、国家开场、正文与暂停。

## 2.4.1：地图图片兼容修复

用户反馈iPad Safari点击国家后，地图素材只剩名称，图片没有显示。这不符合预期。原地图在SVG的foreignObject里放置带相对定位、圆角裁切和独立绘制层的HTML图片；这一组合有[WebKit已记录的绘制/变换问题](https://bugs.webkit.org/show_bug.cgi?id=23113)，与反馈现象相符，但未在用户实体设备上远程确认根因。

- 地图素材改用原生SVG image、圆形clipPath、文字与点击区域，大洲大洋控件也使用SVG；地图内不再有foreignObject。使用现有160像素JPEG缩略图，同时提供href与旧版xlink:href。277张小图合计1,490,791字节，沿用版本化地址与长期缓存，未引入原图下载。失败时保留动物符号和名称，保留键盘、点击、分组与当前选中状态。
- 发现并修复一个独立问题：在国家定位动画尚未完成时改变视口尺寸，会中止定位并把该国素材留在屏幕外。现在旋转或Safari工具栏改变尺寸后继续到达尚未完成的目的地；定位完成后的旋转仍保留当前中心，主动拖动可取消自动定位。
- 34项Node测试、全素材检查与生产构建通过。新增真实组件渲染检查覆盖唯一裁切ID、可访问按钮、图片尺寸、分组数量，以及肯尼亚、中国、埃及视图不再产生HTML图片层。
- 本地生产包在测试浏览器完成1366×1024与1024×1366检查：肯尼亚16张、埃及6张、中国34张地图图片存在并可见；点击河马和圣甲虫打开对应介绍；拖动/缩放后图标宽度保持47像素；世界图片分组仍可展开。定位中国时立即切换视口后，定位继续完成且34张图标可见。页面没有横向溢出，控制台错误/警告为0。
- 没有完成实体iPadOS 14.2验证，不将桌面测试浏览器当作旧Safari实机。
