# 图片、音频与缓存优化记录

更新：2026-11-14。

## 已有与本次改进

原来已有240像素JPEG小图、按需加载、AAC音频和版本参数。本次继续优化：

- 地图使用160像素WebP/JPEG，内容列表使用320像素小图；详情提供640/1280长边版本。浏览器用`picture/srcset/sizes`选择格式与尺寸，不会同时下载所有版本。
- 支持WebP时优先使用WebP，不支持时回退JPEG。大图只在对应内容被打开时加载，照片放大后按需取较大版本。
- 图像和音频文件名/目录均含内容版本；新素材发布后使用新地址，旧素材保持浏览器缓存。
- 图片校正原始旋转方向，按动物主体裁切；公开衍生图清除EXIF/XMP，原图保存在不进Git/Docker的素材目录。
- 音频沿用48kbps AAC/M4A，点击播放时才创建Audio，不会在首页预取319段讲解。

## 实测文件体积

| 项目 | 体积 |
|---|---:|
| 本次10张用户原图 | 13.22 MB |
| 10张实拍的默认WebP大图合计 | 1.12 MB |
| 10张实拍全部发布衍生图（含JPEG、WebP、各尺寸） | 4.27 MB |
| 全部237条目地图WebP小图合计 | 1.07 MB |
| 全部参考与实拍原稿合计 | 67.69 MB |
| 全部243张配图的最大WebP版本合计 | 33.22 MB |

10张实拍的WebP大图相对原图减少约91.6%。这不是整包大小的减少比例：发布包保留兼容格式和多尺寸文件，总图像文件约115.57 MB，浏览器每次只选择需要的版本。

JSON、JavaScript、CSS、SVG及地理数据在Nginx启用Gzip，压缩等级5并设置`Vary: Accept-Encoding`。例如图片索引原始372,413字节，Gzip后约40,251字节；世界底图由218,498压到约75,184字节。音频与图片本身已压缩，不再叠加Gzip。

## 生产缓存策略

| 资源 | Cache-Control |
|---|---|
| `/assets/`、`/media/`、`/audio/`的版本化文件 | `public, max-age=31536000, immutable` |
| HTML、`/data/*.json`、底图索引 | `no-cache`，通过ETag重新验证，未变化时可返回304 |

新增图片或改稿会更新版本化地址；浏览器可继续复用其他未变化的素材。页面不会因一年缓存而一直显示旧照片。
