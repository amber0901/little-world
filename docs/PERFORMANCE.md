# 图片、音频与缓存优化记录

更新：2026-11-15，版本2.4.1。277项内容、283张图片、359段正文与700段国家开场。

## 按需要加载

- Safari 14通过IntersectionObserver延迟挂载列表图片，详情配图限制为640长边，点击大图后再使用完整版本。
- 地图改用SVG原生image与160像素JPEG小图，避开旧Safari的foreignObject图片绘制问题；277张地图JPEG小图合计1.49MB。内容列表通过picture/srcset/sizes选取WebP/JPEG与160/320像素小图，详情限制为640长边，大图才选取完整分辨率。
- 大图在对应内容被打开后加载，照片放大后再取合适的大版本。38张新图已逐张查看，新动物和地标详情尽量保留完整主体。
- 音频使用与百家姓相同的云小朵女童声，24kHz单声道、64kbps AAC/M4A，faststart。孩子点击后才加载当前国家开场及正文，不预取1059段声音；不同国家共用同一段正文，避免重复保存完整故事。
- 国家开场索引约53,757字节，Gzip等级5后约15,083字节。新增开场主要增加存储量，不会让首页下载全部声音。
- 图像修正旋转、缩放并清除EXIF/XMP；原图仅在本地materials归档，不进入Git或Docker。10张亲子原图保持不变。

亲子照片最大WebP相对原图减少约91.6%。公开目录同时保留兼容格式和不同尺寸，所以整包存储体积不同于浏览器一次访问的下载量；不会同时下载表中的全部版本。

图片索引437,530字节，Gzip等级5后约46,888字节；世界底图由218,498压到约75,184字节。Nginx对JSON/JS/CSS/SVG启用Gzip和Vary: Accept-Encoding，压缩后的图片、音频不重复Gzip。

## 生产缓存

| 资源 | Cache-Control |
|---|---|
| /assets/、/media/、/audio/中的版本化文件 | public, max-age=31536000, immutable |
| HTML、/data/下的图片/正文/国家开场索引及底图 | no-cache，配合ETag重新验证 |

新图片和声音采用新内容地址，未变资源可继续复用缓存。国家开场和正文共享同一个媒体元素播放，兼顾浏览器播放权限与暂停/继续；切换国家或内容会取消旧队列。更换音色时所有声音内容地址已更新，不会复用旧音色缓存；播放端不使用设备系统朗读。

## 验证边界

图片沿用前版已验证的2246个JPEG/WebP文件，未更改图片内容。本轮1059段新音频全部通过完整AAC解码、24kHz单声道格式、时长与文件哈希检查，所有索引核对了文字、SSML和统一音色配置指纹。14段代表性内容完成离线转写辅助检查，9段抽测编码后响度与峰值，未发现削波。具体数据见[VOICE_QA.json](VOICE_QA.json)。浏览器播放与平板检查见[验收记录](VERIFICATION.md)。

本机未安装Docker/Nginx，上述Gzip数值为本地同等级压缩结果，生产HTTP响应头与304行为尚未在腾讯云实测。原始数值见[PERFORMANCE.json](PERFORMANCE.json)。

拖动时按动画帧更新可见节点位置，松手后再重算图片分组；地理归属提前生成，避免在浏览器遍历国家多边形。详情主配图总体积相对最大版本减少约58%，不改变大图内容。已加入Safari 14视口、间距与全屏接口兼容，实测与边界见[iPad优化记录](IPAD_OPTIMIZATION.md)。
