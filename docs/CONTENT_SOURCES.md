# 内容依据与编辑说明

整理日期：2026-11-14。内容在 `src/data.js` 及相应扩展模块中维护，中文介绍是为儿童重新撰写的简短概述，不复制原文。

## 当前范围

- 70 个主要国家；七大洲、五大洋。
- 277 个内容：92 个陆地动物、鸟类或保守类群、36 个海洋生物、50 个明确物种的甲虫、89 个地标与风景、10 个自然之最。
- 肯尼亚河马、印度印度犀均有独立介绍；操作集中于地图与知识介绍。
- 本次10张亲子实拍增加白犀、鹈鹕属、长鼻浣熊属、巨嘴鸟属、陆龟科五项；识别边界见[实拍记录](ZOO_IDENTIFICATION.md)，不把知识牌当活体照片。
- 本文保留基础内容的逐项依据。新增90个自然条目见 [自然研究](NATURE_RESEARCH.md)，新增31国家与64个地标见 [地理研究](PLACES_RESEARCH.md)。

## 地理与物种口径

1. 采用中文常见的七大洲划分，包含大洋洲；“大洋洲”比澳大利亚大陆范围更广。五大洋包含南大洋。参考 [National Geographic 地图口径](https://www.nationalgeographic.org/national-geographic-map-policy)。
2. 每个条目的坐标是适合儿童地图定位的代表点，不是完整分布范围。全图采用原始代表点；国家或大洋视图对跨区物种使用地区中心的关联示意，散开时有地理引线，界面有提示，不作为精确栖息位置。动物可能分布于多个国家；国家关联表示可帮助理解的野外分布或明确写出的家养分布，不等于该国独有或法定国兽。国家列表不是全球完整政治实体目录。
3. 俄罗斯、土耳其等跨洲国家在数据中按一个主要分组放置，文字说明跨洲事实。南极洲不是国家。海洋动物不按国界限制；条目说明适合的海域和迁移。
4. 鸟类与半水生哺乳动物放在“陆地动物”探索组，以便关联陆地国家；帝企鹅单独关联南极洲，不虚构所属国家。
5. 印度犀：Rhinoceros unicornis，大独角犀，主要野生种群位于印度和尼泊尔。河马指普通河马 Hippopotamus amphibius，不把西非侏河马混为一谈。
6. 昆虫均指定物种，避免把某个习性泛化到整个科：七星瓢虫 Coccinella septempunctata、独角仙 Trypoxylus dichotomus、欧洲锹甲 Lucanus cervus、光肩星天牛 Anoplophora glabripennis、玫瑰金龟 Cetonia aurata、圣甲虫 Scarabaeus sacer、欧洲萤火虫 Lampyris noctiluca、绿虎甲 Cicindela campestris。萤火虫也是鞘翅目的甲虫。
7. 海豚、蓝鲸、独角鲸等使用清楚的物种或通用分类名称；鲸鲨是鱼类、虎鲸属于海豚科、鸭嘴兽是卵生哺乳动物、考拉不是熊。
8. 地图元素优先使用真实照片缩略图。甲虫照片对应具体物种；海沟采用地理示意图，并在图注注明。作者与许可证见图片素材清单。

## 世界之最的比较标准

- 山峰前三名按山顶海拔：珠穆朗玛峰 8848.86 米、乔戈里峰 8611 米、干城章嘉峰 8586 米。不是从山脚起量的山体高度。珠峰雪面高程采用中国、尼泊尔 2020 年共同公布结果，参考 [国家体育总局](https://www.sport.gov.cn/n315/n20067006/c20257594/content.html)；排名及其余高度参考 ICIMOD 与 Guinness。
- 里海同时是面积最大的内陆湖和盐水湖；不是最咸的湖。面积随水位变化，因此儿童卡片不固定写一个面积数值。
- 苏必利尔湖的纪录按通常分开命名的单体淡水湖的湖面面积比较。密歇根湖与休伦湖在水文上连通，合计面积更大，已在 comparison 字段明示。参考 [密歇根州政府五大湖说明](https://www.michigan.gov/egle/public/learn/great-lakes)。
- 贝加尔湖按天然淡水湖的最大深度与水量比较。UNESCO 页面使用约 1700 米的概数，精确最大深度 1642 米以 Guinness 所引测深研究为准。
- 马里亚纳海沟卡片使用最深处约 11000 米，避免把不同年份、仪器、声速修正产生的精确数字说成没有误差的唯一数值。
- 撒哈拉是最大的热沙漠；南极是包含寒冷极地沙漠后的最大沙漠。沙漠的依据是降水稀少，不要求必须覆盖沙子。
- 安赫尔瀑布采用常见的地面瀑布总落差口径：约 979 米，主要连续落差约 807 米；不把海底密度流算作瀑布。

## 资料使用方式

优先参考动物园、博物馆、保护组织、政府与国际机构。少量常见物种的简短基础事实以维基百科条目作补充来源，已逐项公开列出；没有把这些补充资料伪称为原始研究。未引用易变化的野生种群数量和旅游价格。资料链接用于家长/维护者核查，孩子界面不需要跳往外站。
