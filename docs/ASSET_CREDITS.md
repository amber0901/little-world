# 图片与素材署名

275个条目使用271张参考配图及10张用户提供的动物园照片（包含1张园区知识牌照片）。亲子实拍只获得本项目使用授权，不自动采用MIT或CC许可。参考图片来自Wikimedia Commons，遵循各自许可。

公开版本经过裁切、缩放和格式压缩，地图和列表使用专用小图。原图仅在本地素材目录归档，用户照片的EXIF/XMP未带入公开图片。马里亚纳海沟为地理示意图，白犀的用户照片为知识牌，界面均有标注。
