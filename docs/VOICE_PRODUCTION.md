音色编号、原生语速与采样率已再次对照百家姓《乌衣巷》《登科后》的正式配置，三项完全一致。完整结果见[验收记录](VERIFICATION.md)与[音频检查数据](VOICE_QA.json)。

## 与百家姓一致的参数

对照本地百家姓正式发布的诗歌配置，以及其已接受的原生韵律制作方案：

| 参数 | 小小世界使用值 |
|---|---|
| 服务 | 腾讯云TextToVoice |
| 音色 | 云小朵，403000，女童声 |
| 原生语速 | −0.65 |
| 源采样 | 24000 Hz，单声道WAV |
| 停顿 | 标点由模型自然处理；介绍各段之间增加300ms SSML停顿 |
| 音量处理 | 与百家姓相同，仅恒定增益：目标−20 LUFS，真峰值不超过−2 dBTP，两者取较小增益 |
| 网页文件 | AAC/M4A，64kbps，24kHz，单声道，faststart |

保留模型原始语调，不做后期变速、变调、截剪语音或统一补静音。超过接口150字限制的5段长讲解按自然段分批合成，保留每段完整原生音频，在段落边界以300ms间隔合并后统一调整增益和编码。AAC编码可能带来很小的峰值变化，母带增益留有余量。

腾讯云官方资料：[音色列表](https://cloud.tencent.com/document/product/1073/92668)、[TextToVoice接口](https://cloud.tencent.com/document/api/1073/37995)、[SSML停顿](https://cloud.tencent.com/document/product/1073/49575)。计费以账号的服务套餐与实际调用为准。

## 后续制作

只部署项目不需要语音服务凭据。重新制作时，需要Node.js、Python 3（仅标准库）及FFmpeg：

```sh
# 只检查计划，不调用服务
npm run assets:audio -- --dry-run

# 本地环境已设置TENCENTCLOUD_SECRET_ID、TENCENTCLOUD_SECRET_KEY时
npm run assets:audio

# 或读取本地忽略的凭据文件，环境变量优先
npm run assets:audio -- --env-file .env

# 单独生成样音；不更换正在使用的索引
npm run assets:audio -- --only hippo,context-KEN-hippo --env-file .env

# 作者工具的缓存与中断保护测试（Docker构建不需要Python）
python3 -m unittest discover -s tests -p 'test_narration_authoring.py' -v
```

音色配置在`scripts/narration-profile.json`。文字、SSML、音色、语速、母带或编码参数改变，都会使对应录音指纹失效。工具优先复用`public/data/audio-production.json`中指纹和文件哈希一致的已发布录音，因此新电脑从Git拉取后只需制作新增或更改的条目。

服务成功响应与原始WAV一起原子保存在忽略的`materials/narration/`缓存内；转换失败可直接继续，不再请求服务。调用前记录请求意图；若网络超时、响应不明或进程中断，未完成的请求会阻止自动重试，维护者需核对该请求的实际状态。明确拒绝的请求可在解决原因后重新运行。核对日志后如决定重试某个未收到结果的片段，可使用`--retry-uncertain 条目ID`显式继续，工具会保留原请求日志；这可能重做该片段。默认并发3，允许1–4。

所有片段准备完成后才替换公开索引，并清理过时录音。每个索引文件原子替换；整个目录不提供在线事务发布，维护命令应在本地或镜像构建前运行，完成检查后统一部署。不要在正在服务的静态目录内直接运行制作命令。

## 前端与检查

359段正文、700段国家开场共1059段音频，运行时无需API、账户登录或外部语音网络请求。孩子点击后才下载当前片段；国家开场和正文共用一个媒体元素，支持暂停、继续和切换取消。声音索引未加载好或文件播放失败时显示重试提示，不启用设备系统朗读。

公开制作记录仅保存音色配置、文字/输入/文件指纹、时长和增益，不包含密钥、原始服务响应或本地路径。`npm run check:assets`核对所有片段的当前文字、统一音色配置与完整文件哈希，防止更换音色时误复用旧录音。制作记录不由前端加载。

音频采用带内容哈希的新地址，保留一年immutable缓存；索引通过ETag重新验证。更新后浏览器会请求新声音地址，既有缓存不会覆盖新音色。
