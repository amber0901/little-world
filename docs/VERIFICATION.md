# 语音替换与整体验收

日期：2026-11-15（Asia/Shanghai）。版本：2.3.0。

## 本轮语音替换

359段条目、国家、大洲和大洋正文，以及700段国家关联开场，共1059段录音，已全部替换为腾讯云云小朵女童声（403000、原生语速−0.65、24kHz）。三项参数与百家姓《乌衣巷》《登科后》的正式配置一致。没有复用旧音色文件，公开音频目录仅保留1059个当前版本的M4A。

保留原生语调，段落间使用300ms SSML停顿；5段超过接口长度限制的介绍按自然段分批生成，再保留完整原始音频合并。仅调整恒定增益，不后期变速或变调。网页使用64kbps单声道AAC/M4A与faststart。

播放端只使用预制音频，移除设备系统朗读后备方案；加载或播放失败时显示提示。国家开场和共享正文继续使用同一个媒体元素，支持暂停、继续、重播及切换取消。切换内容时清理上一次的错误提示。

## 内容与性能

保持70个国家、七大洲、五大洋及277项内容：92个陆地动物或保守识别类群、36种海洋生物、50种甲虫、89项地标与风景、10项自然之最。凯门鳄、长戟大兜虫、独角仙、毛象大兜虫、加拉帕戈斯象龟和亚达伯拉象龟的条目或搜索别名保持完整，见[核对记录](REQUESTED_ANIMALS.md)。

保留动物园照片的属/科级识别边界；国家开场说明地图入口，不把动物园拍摄地点误说成对应国家的野生拍摄地。图片内容、地图和搜索逻辑沿用前版已验收版本，本轮没有增加游戏、上传或前端素材管理功能。

音频点击后才加载，先播短国家开场，再取共享正文；本轮音频合计约98.29MB，不作为首页一次性下载量。图片继续使用WebP优先与多尺寸按需加载。版本化资源沿用一年immutable缓存，数据索引重新验证，所有新音色文件均采用新内容地址。国家开场索引Gzip约15KB。完整数值见[性能记录](PERFORMANCE.md)。

## 验证边界

iPad尺寸在桌面浏览器中模拟，未使用实体iPad Safari测试手势、扬声器与真实设备自动播放策略。播放器复用同一个媒体元素衔接开场与正文，已在本地浏览器验证并以单元测试覆盖竞态。

本机未安装Docker/Nginx，未运行镜像或实测腾讯云生产缓存响应头。Docker构建会运行Node测试、素材检查和打包，不需要Python、FFmpeg或腾讯云语音密钥。对外端口仍默认8091。没有连接腾讯云服务器或重启生产服务。
