# 搜索、国家讲解与内容扩充验收

日期：2026-11-14（Asia/Shanghai）。版本：2.2.1。

## 本次指定名称补充

新增眼镜凯门鳄与加拉帕戈斯象龟类群；毛象大兜虫、亚达伯拉象龟补充既有条目的搜索别名，详情和正文讲解显示常见叫法。长戟大兜虫、独角仙保留原条目。六个查询均由回归测试检查，不重复建立既有物种。

海岛动物通过国家进入时仍保留真实岛屿代表点，并飞往该点；不因底图省略小岛而移到国家大陆中心。浏览器已核对厄瓜多尔→加拉帕戈斯象龟的国家开场、正文衔接和完整图片，毛象别名显示/播放、亚达伯拉检索、凯门鳄配图均正常。

详见[核对记录](REQUESTED_ANIMALS.md)。

## 当前内容

- 70个国家，七大洲、五大洋，277个动物和地理条目。
- 92个陆地动物、鸟类或保守识别类群、36种海洋生物、50种甲虫、89项地标与风景、10项自然之最。
- 283张图片资产，含原有10张亲子照片；359段条目/国家/大洲/大洋正文，700段国家关联开场，共1059段本地AAC/M4A。
- 新增38项：12种甲虫、8种陆地动物/鸟类、4种海洋生物、14项国家地标/自然景观。
- 原有237项及70国讲解完成通读，为36项补充一条短知识；10项自然之最同时朗读比较口径。新增内容来源分别核查。
- 保留亲子照片的属/科级识别边界。国家开场说明当前地图入口，不把动物园照片误说成在对应国家实拍。
- 仍以地图、图片与讲解为主，没有上传、任务、奖励或活动进度功能。
