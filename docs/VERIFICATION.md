# 地图与亲子照片验收记录

日期：2026-11-14（Asia/Shanghai）。本记录对应2.1亲子照片版。

## 当前范围

- 70个国家，七大洲、五大洋，237个动物与地理条目。
- 82个陆地动物、鸟类或保守识别类群、32种海洋生物、38种甲虫、75项地标与风景、10项自然之最。
- 243张本地图片资产，含10张用户照片；319段中文讲解。
- 十张照片全部接入：鹈鹕、白犀知识牌、大食蚁兽、狐獴、长鼻浣熊、巨嘴鸟、陆龟、水豚、河马、蓝孔雀。
- 用户明确没有具体名牌记录，鹈鹕、长鼻浣熊、巨嘴鸟只认到属，陆龟只认到科；四条类群的地理关联是分布示例，不推断照片个体原生地。白犀知识牌不作活体封面。
- 保持地图为主界面，没有任务、护照、奖励、印章、发现计数、随机旅行、独立图鉴或前端素材上传入口。

## 地图表达与缓存

全图使用内容代表点，不声称完整分布范围。地区视图把跨区物种放在所选国家或大洋的中心示意关联；分开排列的图片使用引线，并有说明文字。建筑与自然景观保留地理坐标。全图分组按代表点实际所在大洲处理。

图片提供地图160像素、列表320像素、详情640/1280长边版本；按需加载，WebP优先，JPEG兼容。音频按点击播放加载。Nginx为版本化资源配置一年immutable缓存，HTML及索引用ETag重新验证，并对文本开启Gzip。完整体积、格式与缓存说明见[性能记录](PERFORMANCE.md)。
